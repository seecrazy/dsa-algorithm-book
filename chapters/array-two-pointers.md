## 1. 数组的本质

数组用连续内存换来了一个承诺：`a[i]` 可以 O(1) 到达。这个承诺带来三件事：

- 下标就是状态；
- 排序后局部具有方向性；
- 插入删除通常要搬移元素。

## 2. 双指针的三种基本形状

### 2.1 对撞指针

用于有序数组或回文判断。

```python
left, right = 0, len(a) - 1
while left < right:
    # 根据比较移动一边
    left += 1
    right -= 1
```

不变量：`[0, left)` 和 `(right, n)` 是已经排除的区域。

### 2.2 快慢指针

用于原地删除、找中点、判断循环。

```python
slow = 0
for fast in range(len(a)):
    if keep(a[fast]):
        a[slow] = a[fast]
        slow += 1
return slow
```

不变量：`a[:slow]` 是满足条件的最终前缀。

### 2.3 滑动窗口

用于连续区间统计。

```python
left = 0
for right, x in enumerate(a):
    add(x)
    while invalid():
        remove(a[left])
        left += 1
    update_answer(left, right)
```

不变量：窗口 `[left, right]` 要么始终满足条件，要么处于收缩修复中。必须明确定义到底维护哪一种。

## 3. 什么时候数组题会变难

- 有重复元素；
- 修改输入与保留输入的需求冲突；
- 正负数混合导致排序性质失效；
- 最优区间不满足单调性；
- 需要维护多个统计量，如最大值、最小值、乘积、计数。

## 4. 陷阱清单

- `left <= right` 还是 `left < right`，必须跟答案定义一致。
- 空数组先返回，再访问 `a[0]`。
- 乘积题不能只维护最大值，要同时维护最小值，因为负负得正。
- 滑动窗口中删除元素时，计数变 0 必须真的从状态中移除。
- 排序可能破坏“返回原数组下标”的要求。

## 5. 自查三问

1. 每个指针代表什么边界？
2. 哪段区域已经处理完？
3. 循环结束时，`left`、`right`、`slow` 的语义是什么？

> 双指针不是技巧，是“用两个下标维护一段被证明安全的区域”。
